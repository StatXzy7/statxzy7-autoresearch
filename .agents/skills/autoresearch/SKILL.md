# AutoResearch

将研究目标变成可执行、可比较、可恢复的实验。先建立可信基线和固定评价协议，再围绕方法假设开展迭代，最终交付可重跑的方案及有证据支持的结论。本目录包含完整流程、模板和辅助工具，可单独安装使用。

## 确定研究合同

从用户提供的论文、代码、数据和算力条件中明确目标：复现哪项结论、优化哪个指标、哪些算法部分可修改。核对实际入口、输入输出和评价调用链；区分算法改进、超参数搜索与工程加速。

把任务范围、固定协议、对照、数据划分、资源预算、完成条件与停止条件写入 [研究计划](assets/research-plan.md)。已有明确约定时直接沿用；缺少会影响费用、可比性或交付的关键信息时再澄清。模板中的空值表示尚未确定，不能作为启动依据。

构建供其他 Agent 执行的任务时，按 [任务设计](references/task-design.md) 提供可运行起点、清晰可写接口、公开评价入口和受保护的最终评价。开展自己的实验时，可直接使用相同实验合同，无需额外构建任务包。

## 建立可运行起点

按 [环境与运行](references/execution.md) 核实主机、解释器、依赖、数据、设备与可写磁盘。先运行小规模端到端实验，确认真实数据经过方法和评价器产生结果，再安排正式预算。环境探测或极小 GPU 运算只证明对应链路可用。

Baseline 是健康、来源可解释且可执行的对照。声明全部正式 seeds 或重复次数，固定数据、预处理、评分、质量要求与预算。训练型实验保存独立训练的 checkpoint，并在新进程中重载评价。不要用故意削弱的对照、最差一次运行或未执行的论文数值证明改进。

## 迭代方法

每轮先写可检验的假设和预期影响，再实现、评分、分析并保留或回退。用 [结果与复验](references/results.md) 记录实际命令、协议、seed、原始指标、配置、源码身份和产物。保留失败与超时，不在同一 run ID 上重试。

只比较同协议与可比资源下的结果。随机任务使用配对 seeds 并报告波动；一次分数改善只能作为观察。按事先冻结的 Dev 汇总规则选择最佳方案，最终评价不回流调参。

任务需要归一化评分或证明存在可改进空间时，按 [基线、参考方案与目标标定](references/calibration.md) 建立 B、R、U。一般方法优化可以直接报告原始指标，无需凭空设定 U。目标值和阈值必须在正式比较前确定，并有方法、噪声和预算依据。

## 持续运行与恢复

模型、推理档位、模型数量和预算由当前任务配置决定。逐一核验实际可用通道，先完成短运行，再启动已授权的持续实验。比较多个 Agent 时使用相同干净起点、题面、评价规则与资源，隔离彼此输出及私有答案。

`scripts/agent_loop.py` 可监督显式提供的 CLI 命令。它管理轮数、墙钟上限、失败次数与恢复状态，不实施 GPU、网络、凭据或费用隔离。实际权限与资源边界必须由执行环境落实并验证。有效研究时间与安装、排队、阻塞时间分别记录；运行时长本身不证明研究质量。

中断前更新 `resume.md`：当前方案、证据路径、未完成项、正在运行的进程身份和下一步。恢复时先核验旧进程与子进程状态、代码和协议身份，再继续原预算；不能因终端断开就重复启动实验。

## 完成与交付

在固定 Dev 协议下确定最佳方案，恢复完整源码、配置和模型，在干净进程中复验。将最终评价和开发结果分别报告，说明差值、波动、实际成本和未验证项。没有提升也可以形成有效结论，但不能宣称已达成改善目标。

交付可运行入口、环境说明、冻结协议、完整候选、必要模型或可获取位置、实验索引、失败记录及恢复命令。按 [交付检查](references/delivery.md) 逐项核对证据，使用 [结果摘要](assets/run-summary.json) 记录真实状态。环境就绪、Agent 运行、论文复现、方法改进和最终复验分别判断。

## 辅助工具

全部工具使用 Python 3.9 或更高版本的标准库；实际算法依赖由研究项目管理。

| 工具 | 作用 |
|---|---|
| `scripts/probe_environment.py` | 本地或 SSH 环境探测，可选极小 CUDA 运算 |
| `scripts/research_run.py` | 单次实验、超时、日志、指标与产物哈希绑定 |
| `scripts/calibrate.py` | B/R 全 seed 配对、U 证据及不裁剪归一化 |
| `scripts/agent_loop.py` | 已验证 Agent CLI 的有界执行、停止与恢复 |

工具不会自动创建沙箱、判断论文结论或替代科学审查。空模板、合成 fixture、退出码和单元测试均不能作为真实研究完成证据。
