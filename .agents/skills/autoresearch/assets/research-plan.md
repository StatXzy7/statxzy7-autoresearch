# 研究计划

## 目标与范围

- 研究问题及预期交付：
- 论文、代码或方法依据：
- 本次复现或优化的具体结论：
- 可修改方法、冻结部分与理由：

## 固定协议

- 数据版本、划分与样本身份：
- 主指标、方向与质量约束：
- Baseline 的来源、实现与健康检查：
- seeds、重复方式、聚合和最佳方案选择规则：
- 训练量、预训练资源、评价代码与协议 ID：
- 最终评价的独立性与访问边界：

## 执行配置

按 [任务配置](task-config.json) 填写已核验的环境与预算。该文件是计划模板，工具不会自动读取或实施其限额；启动时需显式传入对应 CLI 参数，并由实际环境落实资源限制。

- 主机、目录、解释器、设备与依赖：
- 模型与工具通道（需要 Agent 时）：
- 时间、实验次数、GPU、并发及费用上限：
- 失败处理、停止条件及预算执行方式：
- checkpoint、持久存储及恢复入口：

## 实验安排

- 端到端最小实验与通过证据：
- 正式基线及配对比较：
- 待检验方法假设与预期影响：
- 需要时的参考方案与目标依据：
- 最佳方案干净重跑和最终评价：

## 当前状态

- 已完成及证据：
- 失败、限制与未执行项：
- 当前进程/会话身份与下一步：
